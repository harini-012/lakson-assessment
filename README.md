# HPBank – Banking Products Dashboard

## Project Overview

HPBank is a responsive banking dashboard that allows customers to view and manage their banking products through a single, user-friendly interface.

The dashboard displays different banking products, their current status, and important financial details.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Bootstrap Icons

## Features

- **Dashboard Overview:** Displays total, active, and pending banking products.
- **Product Cards:** Displays savings accounts, credit cards, home loans, and investment portfolios.
- **Search Functionality:** Search products by name, category, status, and financial details.
- **Category Filter:** Filter products by Savings, Cards, Loans, and Wealth.
- **Status Filter:** Filter products by Active and Pending status.
- **Product Details:** View detailed information about each banking product in a popup.
- **Apply for Product:** Submit a product application through an interactive form.
- **Transactions:** View recent sample banking transactions.
- **Notifications:** View notification messages through a popup.
- **Settings:** View profile information and manage notification preferences.
- **Responsive Design:** Supports desktop, tablet, and mobile screens.

## How to Run the Project

1. Download or clone the project.
2. Open the project folder in Visual Studio Code or another code editor.
3. Open `index.html` in a web browser.
4. Explore the dashboard and interact with its features.

## Project Scope

This is a frontend demonstration project. It uses sample banking data and JavaScript-based interactions. No real banking transactions, applications, or data storage are connected to a backend.
